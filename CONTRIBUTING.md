# Contributing to ElevDatum

Thank you for your interest in improving **ElevDatum**, the Geodetic & Elevation Data Toolkit.

## Before opening an issue

1. Read the [README](README.md), including installation instructions and limitations of the hosted preview.
2. Check the [existing issues](https://github.com/IslamKOA/geodetic-elevation-data-toolkit/issues) to avoid duplicates.
3. Specify whether you used the **local desktop** edition or **hosted preview**, and which scientific software version you used.

## Bug reports

Please provide:
- A brief description of the expected and observed results.
- Operating system, Python/environment manager, installation method, and version.
- The exact command or workflow step that failed, and relevant error messages.
- Input type (AOI, DEM/DSM, CSV, model grid, GPS time), vertical datum, units, coordinate reference system, and transformations selected.
- Minimal reproducible steps. Use synthetic or shareable sample data when possible.

**Privacy:** Remove credentials, tokens, personal coordinates, sensitive project locations, and private data paths from reports. Do not upload confidential data.

## Feature requests and scientific questions

Explain the geodetic use case, desired output, assumptions about height reference systems, and a relevant public reference or test dataset.

## Pull requests

Keep changes focused. Describe the behavior changed, testing performed, and any impact on existing workflows, archived v5.0.0 results, installation scripts, or scientific reproducibility. Do not silently change transformation conventions, model grids, units, or the citable archived release.
