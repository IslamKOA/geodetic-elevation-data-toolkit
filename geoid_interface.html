Scientific overview

A guided introduction to vertical reference systems and the main processing tools.

Understanding elevation references

Ellipsoidal height h is referenced to an ellipsoid; physical heights H are referenced to a gravity-related vertical datum. A separation model connects their heights.

h = H + N and H = h − N

For RAF20, N denotes the applicable height anomaly (quasigeoid), rather than a universal geoid undulation.

Scientific references: IGN Geodesy · PROJ vertical transformations

01

Extract a geoid separation raster from an AOI

Use an area boundary and create the separation N raster without downloading any DEM. Values outside your AOI are set to NoData.

Select one GeoJSON, GeoPackage or ZIP file. For a shapefile, select .shp + .shx + .dbf + .prj together (Ctrl/Shift-click), or ZIP all components. The .prj enables automatic CRS detection.
Input CRS will be detected from the uploaded boundary.
Paste the complete path to an existing GeoTIFF on this computer. This bypasses the browser upload and 400 MB limit. Use either the file picker or this path, not both.

The original grid, CRS, NoData mask and pixel size are retained. The converted height raster and separation raster(s) are included in the ZIP output.

If z is omitted, the tool returns only the geoid separation. If z is provided, it also calculates the converted elevation.

All original fields are preserved. The tool appends geoid_N_m and, when applicable, z_converted_m.

02

Reference system and vertical model

AOI: input CRS is read from the boundary. Output uses the input projected CRS (metres), or automatically chooses local UTM if the input is geographic. Enter a projected EPSG code to override. Pixel size is in output CRS units. For points/CSV, enter the input coordinate CRS.

Use this only if you have your own geoid separation grid, where N = h − H, in metres. Leave it unused for RAF20, EGM96 or EGM2008.

Conversion rule: h = H + N and H = h − N. For switching between vertical systems: ztarget = zsource + Nsource − Ntarget. All elevations and N values are in metres. Please verify the original datum of your input data before conversion.

05

Download digital elevation models

This section reuses the original v1.0.1 download engines. Choose a DEM source, upload an AOI boundary, and export a ZIP package with the downloaded raster products.

Choose one GeoJSON, GeoPackage or ZIP file, or select .shp, .shx, .dbf and .prj together (Ctrl/Shift-click).
Input CRS will be detected automatically.

Vertical reference & optional height conversion

Copernicus GLO-30 usually references EGM2008.

When enabled, the ZIP includes the original DEM, ellipsoidal DEM, and separation raster.

Formula: h = H + N. Please verify the published datum and ellipsoid of the selected DEM before conversion. RAF20 is a regional height-anomaly surface.

DEM sources have different native vertical references. Copernicus GLO-30 commonly uses EGM2008, SRTM uses EGM96, and IGN LiDAR HD generally uses NGF-IGN69. Downloading a DEM does not automatically convert its vertical datum.

06

GPS Time Converter

Convert GNSS/GPS time to UTC and Unix time, or calculate GPS time from a UTC timestamp. Includes leap-second corrections. The legacy mode preserves the input convention used in your original converter.

GPS and UTC are different time scales. GPS time started on 6 January 1980; GPS − UTC is 18 s from 2017-01-01 through the latest leap-second entry supplied here. Leap-second instants (23:59:60) cannot be represented by JavaScript Date and are flagged rather than silently rounded. For future dates, confirm that the leap-second table is current.

References: GPS time system · IERS Earth orientation and leap-second resources. Results use the effective UTC leap-second dates listed in the toolkit's documentation.

A

Advanced reference DEM workflows

The original Python/Jupyter utility remains available in the advanced_legacy/ folder of this package. It includes Copernicus GLO-30, SRTM, and IGN LiDAR HD downloaders, horizontal reprojection, QC plotting, and full DEM preparation workflows.

For legacy mode, install its requirements and launch advanced_legacy/Reference_DEM_Utility.ipynb in Jupyter.

Local browser utility. Files are processed by Python on your computer through 127.0.0.1. Global EGM models may need a one-time PROJ grid download. RAF20 is intended for mainland France coverage and should not be treated as a generic global geoid.
