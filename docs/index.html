Geodetic & Elevation Data Toolkit

Open-source tools for geoid and quasigeoid modelling, vertical height transformations, digital elevation processing, and GPS time conversion.

Version 5.0.0 · Islam Koa · IGE / INRAE / Université Grenoble Alpes · An-Najah National University

Scientific workflows

Geoid / quasigeoid

RAF20, EGM96, EGM2008 and custom separation models, subject to model availability.

DEM/DSM conversion

Ellipsoidal and model-consistent physical-height transformations for geospatial rasters.

Survey coordinates

Manual points and CSV-based vertical conversions with explicit CRS handling.

Elevation acquisition

Local downloader workflows for Copernicus DEM, SRTM and IGN LiDAR HD.

GPS time

GPS week, GPS seconds, UTC and Unix timestamp conversion.

Reproducibility

Source code, citation metadata, release notes, and RAF20 test routines on GitHub.

Use the complete toolkit

For all scientific processing workflows, download and run the local Python application. New users can follow the step-by-step Micromamba setup, even without an existing Python or Conda installation.

Hosted demonstration: The online preview offers selected small RAF20 AOI, raster and point/CSV operations, plus GPS Time. It uses a free server that can take time to wake up. Large datasets, full EGM options and DEM acquisition require the local edition.
